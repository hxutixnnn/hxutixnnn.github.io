Here are some examples:

- `1.0.0-alpha.1+build.20230704`: This is the first pre-release version of the application, built on July 4, 2023.
- `2.5.0-beta.3+build.20230704`: This is the third beta version of the application, built on July 4, 2023.
- `3.1.0-rc.2+build.20230704`: This is the second release candidate version of the application, built on July 4, 2023.
- `4.0.0+build.20230704`: This is the official release version of the application, built on July 4, 2023 and without any accompanying pre-release metadata.
