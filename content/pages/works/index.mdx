These are substantial projects with their own deployment and release lifecycle. They open outside Tien OS rather than being placed in an iframe.

## Image Restoration

[khoiphucanh.com](https://khoiphucanh.com/?src=hxutixnnn.github.io) is a free online image-restoration service built with Next.js, Tailwind, and Hugging Face APIs. [View project details](/apps/image-restoration/).

## Karaoke Player

[karatube.online](https://karatube.online/?src=hxutixnnn.github.io) is a web karaoke experiment using YouTube video sources and a focused playback interface. [View project details](/apps/karaoke-player/).

## Car Rental Site

[daiphubinhan.com](https://daiphubinhan.com/?src=hxutixnnn.github.io) is a local car-rental site built with Next.js, Chakra UI, and a Notion-backed workflow. [View project details](/apps/car-rental/).
