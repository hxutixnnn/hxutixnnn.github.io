Relay Arcade is an original, compact party-console experiment inside Tien OS. Host **Catch the sparks** on a shared screen, then use the keyboard or open a controller tab in the same browser profile.

The first version is intentionally serverless: it uses browser messaging between same-origin tabs and stays playable solo when no second tab is available.
